Architecture technique de Marcel Pro

L'artisan décrit la pièce. Des agents H Company relèvent les prix chez plusieurs fournisseurs en parallèle, Hugging Face lit les photos, et notre code calcule les quantités, choisit le meilleur prix, date les travaux et pré-remplit le devis. Les agents s'arrêtent toujours avant le paiement.

Une demande, de bout en bout

  1. Comprendre

    Dimensions, postes et photos partent vers l'API. Le code calcule les surfaces, Hugging Face lit les photos, le code génère les questions (photo, mesure ou choix).

    ≈ 5 s

  2. Chercher

    Après les réponses, 3 agents H partent en même temps chez 3 fournisseurs. L'artisan peut les regarder chercher en direct.

    4 à 8 min

  3. Décider

    Le code calcule combien d'unités acheter chez chacun (pots de 2,5 L contre 10 L), choisit le moins cher, fait les paniers, le planning et le devis.

    ≈ 1 s

  4. Livrer

    Le site affiche prix, paniers, devis modifiable et PDF. Supabase prévient n8n, qui envoie le mail à l'artisan.

    ≈ 5 s

Règles de conception et limites

L'IA extrait, le code décide

Les agents ont mis le code-barres à la place de notre référence produit : le code rattache désormais les lignes par leur ordre. Aucun chiffre affiché ne vient d'un modèle sans vérification.

Prix publics uniquement

Sans connexion, on ne voit pas les remises pros. Le site le dit : « ta remise habituelle n'est pas appliquée ».

Pas de contournement

Sur un CAPTCHA, l'agent s'arrête et le signale. Leroy Merlin et ManoMano sont écartés.

Arrêt avant le paiement

Les paniers sont des listes de liens et de quantités : l'artisan commande lui-même.
