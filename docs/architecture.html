Architecture technique de Marcel

Marcel envoie des agents H Company sur les sites des enseignes, Hugging Face comprend la demande et rédige le guide, et notre code vérifie chaque produit au millimètre avant de proposer quoi que ce soit. L'agent s'arrête toujours avant le paiement.

Une demande, de bout en bout

  1. Comprendre

    Photo, texte libre et mesures partent vers /api/comprendre. Qwen3.8-27B en tire une liste de besoins ; le code fixe les tailles maximales et écarte plomberie et électricité.

    1 à 5 s

  2. Chercher

    Après validation, /api/parcours lance un agent H par enseigne. L'utilisateur regarde l'agent naviguer en direct ; le front interroge le statut toutes les 30 s.

    ≈ 5 min

  3. Vérifier

    /api/resultat récupère les réponses par session_id. marcel_core rejette ce qui ne rentre pas, calcule les quantités, choisit, date les travaux et contrôle le budget.

    ≈ 1 s

  4. Restituer

    Qwen rédige le guide à partir des seules données vérifiées. Le front affiche la liste, le planning, le guide et l'objet 3D à l'échelle, visible en réalité augmentée.

    ≈ 5 s (guide)

Règles de conception

L'IA extrait, le code décide

Le code a rejeté les étagères de 800 mm proposées par l'agent pour une niche de 800 mm (maximum 790 mm avec la marge).

Arrêt avant le paiement

Les agents peuvent remplir un panier pour lire le délai de livraison, jamais aller jusqu'à l'adresse ou au paiement.

Pas de contournement

Sur un CAPTCHA, l'agent s'arrête en 2 ou 3 étapes et le signale. Les enseignes concernées sont écartées.

Secrets hors du code

Clés H, Hugging Face et Supabase en variables d'environnement, jamais dans le repo ni dans le front.
